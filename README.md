# Error 404: Revenge of the Nerds
First person shooter game made in Unity for the COMP307 Computer Graphics module. The user is a student on campus fighting against hordes of zombies as they attack the computer science building.
  
# Features: 
## Game Mechanics: 
- Physics-based wall running for advanced traversal
- Grappling gun to allow swinging from buildings and trees
- Multiple available weapons with unique characteristics
- Multiple game modes that alter AI/Zombie generation and behaviour

## Map: 
- Modelled off of the H1 Building at UKZN Westville Campus (our computer science building)
- Made in Blender as accurately as possible
- Only the exterior was accurately modelled, the interiors of the Computer LANs were roughly modelled so that if the ray tracer worked you'd be able to see into it through the glass doors  

## Attempted Feature: Ray Tracing
- Attempted to include a graphic option to allow for ray traced graphics
- Partially worked in some builds, but performance was never good enough to fully include
- Was submitted individually and not as part of the project code
- Still plan on revisiting getting the ray tracer to work properly in the future
